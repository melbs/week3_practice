Already, I feel more comfortable with the program. From the navigation on the left to understanding what VS Code is. I did some Googling about VS Code, who owns it, is it free for all, and how it differs from Visual Studio.

Challenges

One small but annoying (sometimes) thing is the autocomplete of tags. I was following along with the video and when I would try to hit enter half the time it grabbed the autocomplete code. I looked up how to avoid that from happening and I'm currently using the ESC key approach.

Something I have trouble with is dealing with the autocomplete and how to make it work efficiently for me. I like it when I need it. But is there a better way to deal with using let's say, a bold tag? I type the bold tag, it autocompletes, I type the word, then how do I move my cursor to after the end tag? Do I have to manually hit space until I get to the right spot?

Cool Stuff

One small but cool thing I learned was paying attention to the breadcrumb trail in the top part of VS Code with the blue brick icon. I wonder if I type a test will it show a different icon? No, it didn't appear to. Maybe I misunderstood the breadcrumb trail brick icon meaning.

From what I remember, it looks like there is an integration between VS Code and GitHub. I'm curious to know if we will use that in future lessons.

HTML

My base understanding of HTML is from way back in the day, before HTML 5. I enjoy learning the basics such as the purpose of the DOCTYPE declaration and breaking down the tag elements. I think if I begin to deeply understand the HTML tag elements, I can better code, debug, edit, etc. That also includes utilizing Chrome dev tools, where it highlights the different objects and tags. If I'm better able to dissect the tags and overall HTML sections, I think it will make me a better technical writer.

A key takeaway is also learning the two main tag types: block and inline. I've tried to think about it as block tags are a boxed container while inline tags act as shrink wrap, attached to the text.
